# Second Life character data

`avatar_skeleton.xml` and `avatar_lad.xml` are taken unmodified from the Second Life viewer:
https://github.com/secondlife/viewer/tree/main/indra/newview/character

The LOD-0 body meshes `avatar_head.llm`, `avatar_upper_body.llm`, `avatar_lower_body.llm`,
`avatar_eyelashes.llm` and `avatar_eye.llm` come unmodified from the same directory.
